# Merge Checklist — FIRECHRONOS

Run this checklist **in order** when merging both teams' PRs into `main`.

---

## Step 1 — Merge Model Branch First

> Model artifacts (`.json` files in `data/processed/`) must exist before frontend can render.

```bash
# On main, after model PR is approved:
git checkout main
git merge --no-ff model/feature-name -m "merge(model): feature-name"
git push origin main
```

**Post-merge verification:**
```bash
# Confirm processed data is fresh
python -c "import json; d=json.load(open('data/processed/asia_daily_calendar.json')); print(f'Days: {len(d)}')"
# Expected: Days: 2509+

# Confirm model artifacts exist
ls models/artifacts/
# Expected: xgb_anomaly_classifier.joblib, hgb_anomaly_classifier.joblib, etc.

# Restart backend and confirm health
curl http://localhost:8000/api/health
# Expected: {"status":"ok","calendar_days":2509,...}
```

---

## Step 2 — Rebase Frontend Branch onto Updated Main

```bash
git checkout frontend/feature-name
git rebase main
# If conflicts in api.ts or types.ts → Frontend Team resolves
git push origin frontend/feature-name --force-with-lease
```

---

## Step 3 — Run Frontend Build

```bash
cd frontend
npm run build
# Must exit 0 with zero TypeScript errors
```

---

## Step 4 — Merge Frontend Branch

```bash
git checkout main
git merge --no-ff frontend/feature-name -m "merge(frontend): feature-name"
git push origin main
```

---

## Step 5 — Integration Smoke Test

```bash
# Start backend
cd backend && uvicorn main:app --port 8000 &

# Start frontend
cd frontend && npm run dev &

# Manual checks in browser at localhost:5173:
# ✅ Calendar tab loads heat-map grid
# ✅ Geospatial Map tab: map tiles render, orange circles visible
# ✅ 7-Day AI Forecast tab: chart renders, risk badges show
# ✅ Sensor Lab tab: charts render
# ✅ Historical Trends tab: charts render
# ✅ Data Center tab: tables load
```

---

## Conflict Resolution Rules

| Conflict in | Resolved by |
|-------------|-------------|
| `scripts/` | Model Team |
| `backend/main.py` | Discuss in PR; Model Team owns endpoint shapes |
| `frontend/src/api.ts` | Frontend Team |
| `frontend/src/types.ts` | Frontend Team |
| `README.md` | Last merger updates |
